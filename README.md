# همراه‌وام

داشبورد فارسی و راست‌چین برای مدیریت درخواست‌های وام کارکنان. شامل آمار و نمودارها، فیلتر و جست‌وجو، جدول صفحه‌بندی‌شده، ثبت و ویرایش درخواست‌ها و خروجی CSV است. در موبایل بخش‌ها با تب نمایش داده می‌شوند.

## اجرا

```bash
npm install
npm run dev
```

برای بررسی و ساخت نسخهٔ نهایی:

```bash
npm run lint
npm run build
```

## ساختار

- `src/app` و `src/pages`: پوسته و صفحهٔ داشبورد
- `src/components`: اجزای رابط کاربری
- `src/data`: داده‌های نمونه و برچسب‌های فارسی
- `src/hooks` و `src/utils`: هوک‌ها و توابع کمکی
- `src/styles`: استایل‌های برنامه

ساخته‌شده با React، TypeScript، Vite و Recharts.
